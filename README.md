# AI Barbershop Assistant

Sistema de atendimento e agendamento automatizado para barbearias utilizando Inteligência Artificial Generativa. O objetivo do projeto é automatizar interações com clientes, responder perguntas frequentes e organizar agendamentos de forma inteligente.

---

## 📌 Descrição

Este projeto propõe o desenvolvimento de uma plataforma capaz de:

- Receber mensagens de clientes
- Interpretar intenções utilizando IA
- Gerar respostas automáticas
- Auxiliar no agendamento de serviços
- Armazenar histórico de interações

A solução é voltada para pequenas barbearias que desejam melhorar o atendimento e reduzir trabalho manual.

---

## 🎯 Objetivo do Projeto

Desenvolver um MVP funcional de um sistema inteligente de atendimento que:

- Automatiza respostas a clientes
- Organiza informações de forma estruturada
- Utiliza IA generativa para comunicação natural
- Possui arquitetura preparada para escalar

---

## ⚙️ Funcionalidades do MVP

- API para recebimento de mensagens
- Processamento de texto
- Integração com IA para geração de respostas
- Base de conhecimento simples (FAQ)
- Persistência de mensagens e respostas
- Estrutura preparada para evolução

---

## 🧠 Uso de Inteligência Artificial

O sistema utilizará modelos de linguagem para:

- Classificação de intenção
- Geração de respostas automáticas
- Interpretação de mensagens de clientes

Também será aplicada a técnica de **RAG (Retrieval Augmented Generation)** para garantir respostas mais precisas com base em dados da barbearia.

---

## 🏗️ Arquitetura (MVP)

Modelo inicial monolítico:
Cliente → API → Processamento → IA → Banco → Resposta

A arquitetura foi planejada para futura evolução para microserviços.

---

## 🧩 Stack Tecnológica

- Backend: Python + FastAPI
- IA: OpenAI API + LangChain
- Banco de dados: PostgreSQL
- Containerização: Docker + Docker Compose
